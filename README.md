# AJP-2024-PRACTICAL6-A
REVISED LINKED LIST
Step 1: Create a LinkedList<Character> object named 'originalList'.
Step 2: Iterate 10 times to Generate a random character. Add the character to the end of
'originalList'.
Step 3: Create a new LinkedList<Character> object named 'reversedList'.
Step 4: Iterate over each element in 'originalList' in reverse order to get the current element
from 'originalList'.Add the current element to the beginning of 'reversedList'.
Step 5: Print the characters present in 'originalList' and 'reversedList'.
